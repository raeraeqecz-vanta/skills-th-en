# Foundation / พื้นฐาน

Establish trustworthy project context, identify conflicts and limits, and select the right next workflow. These skills do not grant authority to mutate external systems.

ตั้งบริบทโปรเจกต์ที่ตรวจสอบได้ ระบุข้อขัดแย้งและข้อจำกัด และเลือกขั้นตอนถัดไป Skill ในหมวดนี้ไม่ได้มอบสิทธิ์ให้แก้ไขระบบภายนอก

- [setup-skill-context](setup-skill-context/SKILL.md) — inspect and establish project context / ตรวจและตั้งบริบทโปรเจกต์
- [reconcile-work-context](reconcile-work-context/SKILL.md) — reconcile competing sources and prior work / เทียบแหล่งข้อมูลและงานเดิมที่ขัดกัน
- [choose-next-skill](choose-next-skill/SKILL.md) — choose a suitable next skill from current evidence / เลือก Skill ถัดไปตามหลักฐานปัจจุบัน
- [stress-test-and-sharpen](stress-test-and-sharpen/SKILL.md) — find weaknesses and sharpen an idea or system / ค้นหาจุดอ่อนและลับคมแนวคิดหรือระบบ
