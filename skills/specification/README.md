# Specification / ข้อกำหนด

Shape user intent into clear, governed requirements, blueprints, and task breakdowns before implementation.

แปลงเจตนาของผู้ใช้ให้เป็นข้อกำหนด Blueprint และงานย่อยที่ชัดเจนและอยู่ภายใต้ขอบเขต ก่อนเริ่มพัฒนา

- [to-spec](to-spec/SKILL.md) — convert a request or discussion into a concise specification / แปลงคำขอหรือบทสนทนาเป็นข้อกำหนด
- [write-governed-spec](write-governed-spec/SKILL.md) — write a governed, evidence-based specification / เขียนข้อกำหนดที่ควบคุมขอบเขตและอิงหลักฐาน
- [blueprint-to-tasks](blueprint-to-tasks/SKILL.md) — decompose an approved blueprint into atomic tasks / แตก Blueprint ที่ยืนยันแล้วเป็นงานย่อย
