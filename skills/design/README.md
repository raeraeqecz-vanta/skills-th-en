# Design / การออกแบบ

Create or critique user interfaces around real tasks, readable content, coherent visual systems, accessibility, and responsive behavior. Design artifacts and implementation are separate scopes.

ออกแบบหรือตรวจทาน UI โดยยึดงานจริง เนื้อหาที่อ่านได้ ระบบภาพที่สอดคล้อง การเข้าถึง และการแสดงผลหลายขนาด งาน Design และการนำไปเขียนโค้ดเป็นคนละขอบเขต

- [ui-ux-master-craft](ui-ux-master-craft/SKILL.md) — design, implement, or critique distinctive and accessible web interfaces / ออกแบบ พัฒนา หรือตรวจทานเว็บอินเทอร์เฟซที่มีเอกลักษณ์และเข้าถึงได้
